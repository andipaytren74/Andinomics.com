# Andinomics — Smart Financial Dashboard

Aplikasi web untuk mencatat pemasukan dan pengeluaran pribadi, dilengkapi visualisasi grafik arus kas dan manajemen kategori.

## ✨ Fitur

- Tambah, edit, dan hapus transaksi (Pemasukan/Pengeluaran)
- Kategori transaksi
- Pencarian transaksi
- Grafik arus kas (Chart.js)
- Mode gelap/terang
- Penyimpanan data di LocalStorage
- Ekspor/Impor data (JSON)

## 🛠️ Teknologi

- HTML5, CSS3, JavaScript (Vanilla)
- Chart.js
- LocalStorage API
